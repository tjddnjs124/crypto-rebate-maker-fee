# 체결 확률과 LOB 동역학

## 핵심 질문

**Limit order가 언제, 어떤 확률로 체결되는가? 그리고 체결이 정보 거래자와의 거래라면 어떻게 되는가?**

## 이론

### Cont, Kukanov & Stoikov (2014)

LOB 이벤트(한정주문·시장주문·취소)가 미드가격에 미치는 영향을 실증 분석했다.
한정주문이 가격에 미치는 영향은 큐우선도·주문 크기·가격 거리에 의존한다.

**기여:** 체결 확률을 정량화하는 방법론 제공. 리베이트 전략에서 "얼마나 자주 체결되는가"를 모형화하는 기초.

### Cont & Larrard (2013)

LOB의 미시적 구조에서 가격이 어떻게 형성되는지 diffusion limit으로 모형화했다.

**기여:** 큐우선도와 스프레드 동역학의 수학적 기반.

## 체결 확률 모형 요소

리베이트 전략에서 체결 확률은 다음 요소에 의존한다:

| 요소 | 설명 | 영향 |
|---|---|---|
| 가격 거리 | 미드에서 몇 틱 떨어져 있는가 | 1틱 내측이면 높음, 2틱+면 급감 |
| 큐우선도 | 동일 가격에서 앞에 몇 개 주문이 있는가 | 앞에 쌓이면 지수 감소 |
| 시장주문 도착률 | taker flow의 강도 | 변동성·시간대 의존 |
| 경로 의존성 | 그 주문이 놓인 이후 시장이 어떻게 움직였는가 | 미드가 접근하면 체결확률 상승 |
| 부분 체결 | 시장주문이 내 주문까지 도달하지 못할 수 있음 | 큐 앞쪽이면 무시 가능 |

## Adverse Selection과의 연결

체결이 항상 좋은 것은 아니다. **정보가 있는 taker**가 올 때 maker가 체결되면 평균적으로 손해를 본다.
Aleti-Mizrach(2021)의 BTC 선물 가격발견 결과는 선물이 현물을 리드한다는 것을 보여주는데,
이는 현물에서 maker 전략이 선물 정보에 노출된다는 뜻이기도 하다.

자세한 내용은 `../risks/adverse-selection.md` 참조.

## 실무 모형 선택

| 접근 | 장점 | 단점 |
|---|---|---|
| Poisson 도착률 | 단순, A-S 모형과 호환 | 경로 의존성 무시 |
| 큐 시뮬레이션 | 경로 의존성 반영 | 데이터 요구량 큼 |
| Machine learning | 실제 패턴 포착 | 해석 어려움, 과적합 리스크 |

리베이트 전략 초기에는 Poisson 도착률 + 큐우선도 보정으로 시작하고, 데이터가 쌓이면 정교화하는 것이 실무적이다.
